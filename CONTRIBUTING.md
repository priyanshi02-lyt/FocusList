# Contributing to FocusList

Thank you for your interest in contributing to FocusList!

## Development Setup

```bash
git clone https://github.com/priyanshi02-lyt/FocusList.git
cd FocusList
npm install
npm run dev
```

## Running Tests

```bash
npm test
```

## Pull Request Guidelines

1. Ensure all tests pass (`npm test`).
2. Verify production build succeeds (`npm run build`).
3. Follow semantic commit messages (`feat:`, `fix:`, `docs:`, `test:`).
