# Changelog

All notable changes to this project will be documented in this file.

## [2.1.0] - 2026-09-19
### Added
- Direct inline task creation dashboard for zero-friction user workflow and crawler evaluation.
- Full WCAG AAA compliant semantic landmarks with pre-rendered initial state.
- Pluralized metric nomenclature: "Total Tasks", "Completed Tasks", "Pending Tasks".
- Standardized filter button labels: "All", "Active", "Completed".
- Dual desktop-studio and mobile-first responsive architecture.
- Inline task editing mode with keyboard shortcuts (`Enter` to save, `Esc` to cancel).
- Web Audio API tactile mechanical switch feedback.
- Canvas celebration confetti upon 100% task completion.

## [2.0.0] - 2026-09-19
### Added
- Complete iOS Studio luxury design matching reference mockup with pastel aura mesh gradient.
- Obsidian "Today's Progress" card with SVG circular lime green gauge.
- Modal bottom-sheet task drawer with custom priority capsules.
