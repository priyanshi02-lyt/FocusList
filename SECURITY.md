# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in FocusList, please report it privately:

1. **Email**: Send details to `senorita130227@gmail.com`.
2. **Details to include**:
   - Description of the vulnerability.
   - Steps to reproduce.
   - Potential impact.
3. We will acknowledge receipt within 48 hours and work on a rapid patch.

FocusList is a client-side application running locally in the user's browser. User data is stored exclusively in `localStorage` and never transmitted to external third-party servers.
